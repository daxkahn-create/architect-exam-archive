# 築題｜建築師考古題與模擬練習

以繁體中文呈現的建築師高考學習網頁，可直接用瀏覽器開啟。

## 功能

- 依年度或科目瀏覽 110–114 年（2021–2025）考古題，共 67 份原始 PDF。
- 搜尋與篩選年度、科目，閱讀或下載試題、答案與更正答案。
- 從 114 年三科共 51 題官方選擇題中隨機組成模擬練習。
- 即時判分、顯示官方答案及鼓勵話語，支援各科表現與錯題、未答題重練。

## 開啟方式

下載完整專案後，雙擊 `index.html`。GitHub 版本將 PDF 與網頁檔案放在同一層，下載後請保持完整內容。

若需要本機伺服器，可在專案目錄執行：

```sh
python3 -m http.server 8000
```

再開啟 http://localhost:8000 。本專案不需要安裝前端套件或設定 API 金鑰。

## GitHub Pages

如果儲存庫與方案支援 Pages，可在 Settings → Pages 選擇 Deploy from a branch，選擇 main 分支的 / (root) 目錄。此為純靜態網頁。

## 計分方式與題庫範圍

模擬測驗採每題等權重，得分 = 答對題數 ÷ 本回合題數 × 100，四捨五入取整數；未作答不給分。每題第一次作答計分，並以官方更正答案優先。

這是練習用分數，並非正式考試配分。可自動評分的題庫限 114 年建築結構、建築構造與施工、建築環境控制的 51 題精選選擇題。申論、設計及附圖題未納入自動評分，完整原卷仍可閱讀。
